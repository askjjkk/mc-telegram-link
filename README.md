# 🎮 TelegramLink — Minecraft & Telegram Integration

Комплексное решение для связывания игрового аккаунта Minecraft с Telegram-ботом, трансляции игрового чата и удаленного администрирования сервера.

---

## ⚡ Особенности

* 🔗 **Быстрая привязка аккаунта**: Команда `/link` генерирует одноразовый 6-значный код.
* 💬 **Трансляция чата**: Игровой чат пересылается администраторам в Telegram в реальном времени.
* 🛡 **Удаленное администрирование**: Авторизация админов и возможность банить игроков через команду `/ban` прямо из Telegram.
* ☁️ **Облачная архитектура**: Работает через единую облачную базу данных PostgreSQL (Neon.tech).

## 🚀 Сборка и Деплой

### 1. Сборка плагина (Java)

1. Убедитесь, что у вас установлены **JDK 21** и **Maven**.
2. В корне проекта выполните команду:
   ```bash
   mvn clean package
   ```
3. Заберите собранный JAR-файл `TelegramLink-1.0.0.jar` из папки `target/` и поместите его в папку `plugins/` вашего Minecraft-сервера.

### 2. Запуск бота (Python)

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Установите переменные окружения `BOT_TOKEN` и `DATABASE_URL` или укажите их в `.env`.
3. Запустите бота:
   ```bash
   python bot.py
   ```

## 📖 Команды

### В игре (Minecraft):
* `/link` — получить 6-значный код для связки с Telegram.

### В Telegram:
* `123456` — отправить 6-значный код боту для завершения привязки.
* `/t0adp <пароль>` — установить пароль администратора.
* `/t0ad` — войти в режим администратора.
* `/ban <ник> [причина]` — забанить игрока на сервере.
