# TelegramLink

Плагин для Minecraft-сервера (Paper) и Telegram-бот. Связывают игрока в игре с его аккаунтом в Telegram, пересылают игровой чат админам и позволяют банить игроков из Telegram.

## Как это работает

1. Игрок в игре пишет `/link` и получает 6-значный код.
2. Отправляет этот код боту, аккаунты привязаны.
3. Админ входит в бота командой `/t0ad`, после этого ему приходит чат сервера, а командой `/ban <ник> [причина]` он банит игрока на сервере.

Плагин и бот общаются через одну базу PostgreSQL (я использовал бесплатную на neon.tech).

## Что нужно

- Java 21 и Maven для сборки плагина
- Python 3.11+ для бота
- сервер на Paper 1.21+
- база PostgreSQL и бот, созданный через @BotFather

## Сборка плагина

```
mvn clean package
```

Готовый `TelegramLink-1.0.0.jar` будет в `target/`, его кладём в `plugins/` на сервере. После первого запуска откроется `plugins/TelegramLink/config.yml`: впишите данные базы в раздел `database` и перезапустите сервер.

## Запуск бота

```
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN` и `DATABASE_URL`, затем:

```
python bot.py
```

Для хостинга есть `Dockerfile` и `amvera.yml`.

## Команды

В игре:
- `/link` - получить код для привязки

В Telegram:
- 6 цифр кода - привязать аккаунт
- `/t0adp <пароль>` - задать пароль администратора
- `/t0ad` - войти как администратор
- `/ban <ник> [причина]` - забанить игрока

## Важно

Токен бота и пароль базы не храните в коде и не выкладывайте `.env` в репозиторий.
